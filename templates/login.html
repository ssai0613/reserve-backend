Administrator Password Reset

For security compliance, Super Administrator credentials can only be reset via the backend management shell:

python manage.py shell
>>> from accounts.models import User
>>> from django.contrib.auth.hashers import make_password
>>> u = User.objects.filter(user_role='Admin').first()
>>> u.user_pass = make_password('NewPass123')
>>> u.save()
